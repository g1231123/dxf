# DXF 模板服务 - 混合方案实现

## 方案概述

针对大文件（39775个实体，200万行JSON）的性能优化方案。

### 核心策略

1. **快速上传**：2-3秒立即返回
2. **后台处理**：异步提取可编辑参数
3. **智能采样**：只提取关键参数（500-5000个）
4. **批量插入**：1000条/批，避免性能瓶颈

---

## 数据库设计

### 1. 模板表（已有，新增字段）

```sql
ALTER TABLE `dxf_template` 
ADD COLUMN `status` VARCHAR(32) NOT NULL DEFAULT 'ready' 
  COMMENT '处理状态：processing=处理中，ready=就绪，failed=失败',
ADD COLUMN `params_count` INT DEFAULT 0 
  COMMENT '可编辑参数数量';
```

### 2. 可编辑参数表（新增）

```sql
CREATE TABLE `dxf_editable_params` (
    `id` BIGINT AUTO_INCREMENT PRIMARY KEY,
    `template_id` VARCHAR(64) NOT NULL,
    `entity_handle` VARCHAR(32) NOT NULL,
    `entity_type` VARCHAR(32) NOT NULL,
    `layer` VARCHAR(255) DEFAULT NULL,
    `param_name` VARCHAR(64) NOT NULL,
    `param_value` TEXT NOT NULL,
    `param_type` VARCHAR(32) NOT NULL,
    `constraints` TEXT DEFAULT NULL,
    `description` VARCHAR(255) DEFAULT NULL,
    INDEX `idx_template_id` (`template_id`),
    INDEX `idx_handle` (`entity_handle`)
);
```

## 工作流程

### 上传阶段（2-3秒）

```
1. 用户上传 DXF 文件
   ↓
2. 解析 DXF 基本信息（图层、实体数等）
   ↓
3. 上传到 MinIO
   ↓
4. 保存基本信息到数据库（status=processing）
   ↓
5. 添加后台任务
   ↓
6. 立即返回（status=processing）
```

### 后台处理（30-60秒，用户无感知）

```
1. 智能采样：过滤关键图层和实体类型
   - 关键图层：墩身、标注、尺寸、文字、0
   - 可编辑类型：TEXT、MTEXT、LINE、CIRCLE、ARC
   ↓
2. 提取参数：39775个实体 → 500-5000个参数
   ↓
3. 批量插入数据库（1000条/批）
   ↓
4. 更新状态为 ready
```

## API 接口

### 1. 上传模板

**POST** `/template/upload`

**响应**（立即返回）：
```json
{
  "code": 0,
  "message": "上传成功，正在后台提取可编辑参数",
  "data": {
    "id": "xxx",
    "status": "processing",
    "entity_count": 39775
  }
}
```

### 2. 查询状态

**GET** `/template/detail?id=xxx`

**响应**：

## 智能采样策略

### 关键图层

```python
key_layers = {
    "墩身",    # 主要结构
    "标注",    # 尺寸标注
    "尺寸",    # 尺寸线
    "文字",    # 文字说明
    "0"        # 默认层（通常包含主要内容）
}
```

### 可编辑实体类型

```python
editable_types = {
    "TEXT",       # 单行文字
    "MTEXT",      # 多行文字
    "LINE",       # 直线（关键尺寸）
    "CIRCLE",     # 圆（孔洞、桩基等）
    "ARC",        # 圆弧
    "DIMENSION"   # 标注
}
```

### 过滤逻辑

```python
for entity in entities:
    # 必须满足以下任一条件：
    # 1. 在关键图层中
    # 2. 是可编辑类型
    if layer in key_layers or entity_type in editable_types:
        extract_params(entity)
```
