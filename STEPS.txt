================================================================================
Windows 部署步骤 - AutoCAD COM 绘图服务
================================================================================

【你需要准备的】
1. Windows 10/11 电脑一台
2. AutoCAD 2018+ 软件（已安装）
3. 从 macOS 复制的 dxf_render_service 文件夹

================================================================================
第 1 步：复制文件到 Windows
================================================================================

从 macOS 复制整个文件夹到 Windows:

macOS 终端执行：
    cd /Users/czy/Downloads/QGIS
    zip -r cad_service.zip dxf_render_service/

然后：
    1. 把 cad_service.zip 发给 Windows 用户
    2. Windows 用户解压到 C:\ 盘
    3. 得到 C:\dxf_render_service\

================================================================================
第 2 步：检查 AutoCAD 是否启动
================================================================================

在 Windows 电脑上：
    1. 打开 AutoCAD 软件
    2. 新建一个空白图纸
    3. 保持 AutoCAD 窗口可见（不要最小化）

================================================================================
第 3 步：运行初始化脚本
================================================================================

打开文件资源管理器：
    1. 进入 C:\dxf_render_service\
    2. 找到 init.bat 文件
    3. 双击运行 init.bat

你会看到：
    [Step 1/5] Checking Python...
    [Step 2/5] Creating virtual environment...
    [Step 3/5] Installing packages...
    [Step 4/5] Checking AutoCAD...
    [Step 5/5] Starting server...

等待完成，浏览器会自动打开测试页面。

================================================================================
第 4 步：测试绘图功能
================================================================================

在打开的网页中：

    1. 点击 [Connect to AutoCAD] 按钮
       - 看到绿色 "Connected" 表示成功

    2. 选择图形类型：
       - 点击 [Circle] 或 [Rectangle] 或 [Square]

    3. 输入参数：
       - X: 100
       - Y: 100
       - Radius: 50
       - Name: 客厅

    4. 点击 [Draw to AutoCAD] 按钮

    5. 查看 AutoCAD 窗口
       - 应该出现圆和文字 "客厅"

================================================================================
第 5 步：常见问题处理
================================================================================

问题 1：提示 "Python not found"
解决：
    1. 访问 https://python.org/downloads
    2. 下载 Python 3.11 Windows installer (64-bit)
    3. 安装时勾选 "Add Python to PATH"
    4. 重新运行 init.bat

问题 2：提示 "Cannot connect to AutoCAD"
解决：
    1. 确保 AutoCAD 已启动
    2. 确保 AutoCAD 窗口没有被最小化
    3. 右键 init.bat → "Run as administrator"
    4. 重新运行

问题 3：文字显示为 ??? 或乱码
解决：
    1. 在 AutoCAD 中输入命令：STYLE
    2. 选择 Standard 样式
    3. 字体名改为：宋体 或 SimSun
    4. 点击 Apply

问题 4：端口被占用
解决：
    1. 打开 cmd，输入：netstat -ano | findstr 8080
    2. 找到占用 8080 的进程 PID
    3. 输入：taskkill /PID xxx /F
    4. 重新运行 init.bat

================================================================================
文件清单（确保这些文件存在）
================================================================================

dxf_render_service/
├── init.bat              <- 初始化脚本（双击运行）
├── server.py             <- 主程序
├── ws_server.py          <- WebSocket + AutoCAD COM 支持
├── qgis_geojson.py       <- 文件上传
├── test_autocad_windows.html  <- 测试页面
└── requirements.txt      <- 依赖列表

================================================================================
手动启动方式（如果 init.bat 有问题）
================================================================================

打开 CMD 命令提示符：
    cd C:\dxf_render_service
    python -m venv venv
    venv\Scripts\activate.bat
    pip install pyautocad pywin32 ezdxf fastapi uvicorn websockets
    python server.py

浏览器打开：
    http://localhost:8080/test_autocad_windows.html

================================================================================
完成！
================================================================================

服务启动后：
    - 访问 http://localhost:8080 查看测试页面
    - 绘制图形会直接显示在 AutoCAD 中
    - 支持圆、长方形、正方形
    - 支持文字标注

如有问题，检查：
    1. AutoCAD 是否启动
    2. 是否以管理员身份运行
    3. Python 是否正确安装
